Example

PresentEvidence.server.lua

local ReplicatedStorage = game:GetService("ReplicatedStorage")

local PresentEvidence =
    ReplicatedStorage.Remotes.PresentEvidence

PresentEvidence.OnServerEvent:Connect(
    function(player, evidenceId)

        if typeof(evidenceId) ~= "string" then
            return
        end

        local evidence = playerEvidence[player]

        if not evidence then
            return
        end

        if not evidence[evidenceId] then
            return
        end

        processEvidence(player, evidenceId)
    end
)

Important gameplay actions are validated on the server instead of blindly trusting requests sent by the client.
